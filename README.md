# GE360 Rilievo

Frontend mobile minimale per rilievi rapidi in cantiere.

## Filosofia

Il telefono non è un CAD.

1. Disegna la stanza o la forma della casa come su un foglio, anche storta.
2. L'app semplifica il tratto e riconosce i lati.
3. Assegna a ogni lato la misura reale.
4. Porte e finestre si appoggiano al muro più vicino.
5. Il risultato viene salvato come JSON grezzo per il backend GE360.

Dati salvati: tratti grezzi, muri derivati, misura reale per muro, porte, finestre e viewport.
